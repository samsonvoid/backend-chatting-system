POST /api/auth/logout Log out the active session
lock expand_less

Parameters

session_id * required

The unique identifier for the user session to terminate.

string
global

If true, terminates all active sessions for this account.

boolean

Responses

200 Session successfully terminated
401 Unauthorized access or invalid session
Example Code 
curl -X 'POST' \
  'https://api.collabhub.com/api/auth/logout' \
  -H 'accept: application/json' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -d '{
  "session_id": "sess_82jks92",
  "global": false
}'
{
  "session_id": "sess_82jks92",
  "global": false
}

    global: false
  })
